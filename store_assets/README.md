# Google Play 등록 자료

## 파일

- `listing_ko.md`: 한국어 스토어 등록 문구 초안
- `screenshots/01_arrival.png`–`04_recipient.png`: 1080×1920 RGB PNG 스크린샷 4장
- `video_preview.mp4`: Android 기기에서 촬영한 25초 미리보기 초안
- `source/*.svg`: 스크린샷에 문구를 배치한 편집 가능한 원본
- `source/captures/`: SVG에서 사용하는 실제 기기 화면

## 스크린샷 내용

1. 현재 장소 목록과 배경색을 제거한 ‘장소 추가’ 버튼
2. 거제 덕포 해수욕장 도착 알림 설정
3. 덕포 해수욕장 지도 선택 화면
4. 알림 받을 사람으로 ‘개발자 고씨’를 선택한 화면

첫 이미지는 촬영 당시 장소 목록이 비어 있는 상태입니다. 2–4번은 이전에 등록한 거제 덕포 해수욕장 예시 화면입니다. 수신자 화면에는 이름만 보이고 전화번호는 포함되지 않습니다.

## 영상 상태

영상은 현재 목록에서 새 장소 지도 화면으로 이동하는 흐름을 담은 검토용 녹화입니다. 장소 저장, 실제 도착, 알림 발송 장면은 없습니다. 완성된 스토어용 편집본이나 YouTube 게시본이 아니므로 기능 전체를 설명하는 영상으로 사용하기 전에 촬영을 보완해야 합니다.
